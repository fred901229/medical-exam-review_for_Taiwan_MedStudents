🦴 骨科

79 題

踝/足部

  • 最常見踝骨折：isolated malleolar fracture
  • 踝關節外側韌帶：ATFL（最弱）、PTFL（最強）、CFL
  • Ottawa Ankle Rules：Malleolar zone（內/外髁tip或往上6cm tenderness + weight bearing痛）；Midfoot zone（5th metatarsal base tenderness）
  • Thompson's test → Achilles tendon rupture（擠壓gastrocnemius時不會plantar flexion）
  • Mondor sign → calcaneal（跟骨）骨折

膝關節/韌帶

  • Unhappy triad：Medial meniscus + ACL + MCL 撕裂傷
  • 半月板：Type I collagen 纖維軟骨；內側（C型、較易受傷）；外側（O型、覆蓋面積較大）
  • 全膝置換術（TKA）一定切除 → ACL
  • Lachman test / Anterior drawer test / Pivot shift test → ACL rupture
  • Posterior drawer test → PCL rupture
  • McMurray's test / Apley test → meniscus tear
  • posterior sagging sign → PCL rupture

開放性骨折 / Gustilo Classification

    Type傷口大小特點
    I<1 cm清潔傷口
    II1–10 cm中等汙染
    IIIA>10 cm軟組織可覆蓋骨頭
    IIIB>10 cm軟組織無法覆蓋（需皮瓣）
    IIIC>10 cm合併神經血管損傷
  • 最常見致病菌：Staphylococcus aureus

股骨/髖關節

  • Femoral shaft fracture 標準治療：IM nailing
  • Femoral neck fracture 分類（Garden）：I/II = non-displaced；III/IV = displaced
  • Displaced femoral neck fracture：<60歲 → reduction + screw fixation；>60歲 → hemiarthroplasty/THA
  • 最常見併發症：non-union、avascular necrosis
  • Intertrochanteric fracture（Evan's）：Stable → DHS（sliding hip screw）；Unstable → IM screw
  • 股骨頭壞死（ONFH）最常見原因：外傷（股骨頸骨折、轉子間骨折）
  • crescent sign → ONFH
  • Hip dislocation：大部分為 posterior（屈曲+內旋）
  • THA posterior approach 切斷肌肉：obturator internus、superior/inferior gemellus、piriformis
  • Snapping hip 相關肌肉：iliopsoas、iliotibial band、rectus femoris、gluteus maximus、biceps femoris
  • Trendelenburg sign → hip abductor weakness/dysfunction

骨盆骨折（AO Universal Classification）

  • Type A：stable；Type B：partially stable（B1=open book，B2/B3=lateral compression，最常見）；Type C：unstable
  • Pelvic fracture 三高：High energy trauma、High morbidity、High mortality

肩關節

  • 最容易脫位的關節：1st = shoulder；2nd = elbow
  • Shoulder dislocation 最常見類型：向前脫位；最容易傷到神經 → Axillary nerve
  • Rotator cuff（SItS）：Supraspinatus（最常斷裂）、Infraspinatus、teres minor、Subscapularis（唯一在前方）
  • Drop arm test → supraspinatus tear
  • Apprehension test → shoulder anterior instability
  • Jerk test / Kim test → shoulder posterior instability
  • sulcus test → shoulder inferior instability
  • light bulb sign → posterior shoulder dislocation

肘關節 / 上臂

  • 小孩最常見肘骨折：Humeral Supracondylar Fracture（大部分為 Extension，FOOSH）
  • Supracondylar Fx 最常傷到血管：Brachial a.；最常傷到神經：median n.
  • Lateral epicondylitis（Tennis elbow）；Medial epicondylitis（Golfer's elbow）
  • Terrible triad of elbow：elbow dislocation + radial head fracture + coronoid fracture（+ LCUL）
  • Humeral shaft fracture → Radial nerve 受傷
  • Proximal radial fracture → PIN（Posterior interosseous nerve）受傷

前臂/腕部骨折

  • 上肢最常見骨折：Distal radial fracture；最常見類型：Colles' fracture（dorsal tilt）
  • Smith fracture：Distal radial fx + volar tilt
  • Silver-fork deformity → Colles' fracture
  • Chauffeur's fracture：Distal radial fx，含 radial styloid process
  • Galeazzi fracture：Proximal radial fx + distal radioulnar joint dislocation
  • Monteggia fracture：Proximal ulnar fx + radial head dislocation
  • Essex-Lopresti fracture：Radial head fx + DRUJ dislocation + interosseous membrane rupture
  • Scaphoid fracture（最常見腕骨骨折）→ Snuff box tenderness
  • Kienbock's disease：Lunate AVN

手部

  • Carpal tunnel 內容物：Median n.、FDS、FDP、FPL、FCR
  • Phalen's test / Durkan's test / Tinel's sign → Carpal tunnel syndrome
  • Mallet finger（DIP 肌腱斷）：DIP flexion + PIP hyperextension
  • Boutonniere's deformity（PIP 肌腱斷）：PIP flexion + DIP hyperextension
  • de Quervain's syndrome（媽媽手）：1st extensor compartment（APL + EPB）發炎；Finkelstein test 陽性
  • Trigger finger（扳機指）：A1 pulley 狹窄；手指卡 flexion
  • Bennett fracture：thumb metacarpal base（simple split）
  • Rolando fracture：thumb metacarpal base（comminuted）
  • Jones fracture：5th metacarpal base；Boxer's fracture：5th metacarpal neck
  • 手腕最常見腫瘤：Ganglion cyst
  • Popeye deformity → long head of biceps tendon rupture

神經支配（損傷 → 症狀）

  • Median n.：橈側三指半感覺；損傷 → Carpal tunnel syndrome
  • Ulnar n.：尺側一指半感覺；損傷 → Claw hand（4+5th MP過伸+DIP/PIP屈）、Cubital tunnel syndrome
  • Radial n.：損傷 → Drop hand / Drop wrist
  • Proximal tibial fx + fibular head fx → common fibular（peroneal）nerve
  • Tibial shaft fx → deep peroneal nerve

骨腫瘤

  • 骨轉移最常見來源：肺、乳、前列腺、甲狀腺、肝（前列腺 → osteoblastic）
  • 最常見原發性骨癌：MM（Multiple Myeloma）→ CRAB（Hypercalcemia, Renal, Anemia, Bone pain）
  • 最常見良性骨瘤：Osteochondroma
  • 小孩/青少年惡性骨腫瘤：1st Osteosarcoma；2nd Ewing's sarcoma
  • 大人最常見惡性骨腫瘤：Chondrosarcoma
  • Epiphysis 好發：Giant cell tumor、Chondroblastoma、Clear cell tumor
  • Osteoid Osteoma（OO）：Aspirin/NSAIDs 減痛；CT 見 <2cm nidus + sclerotic bone

脊椎側彎 / Cobb angle

  • 脊椎側彎定義：Cobb angle > 10度；mild 10–20；moderate 20–40；severe >40
  • Forward bending test → 脊椎側彎篩檢（看兩側肩膀是否等高）

頭部外傷

  • 腦震盪（Concussion）：無腦實質受傷，僅意識改變
  • Contrecoup injury：撞擊對側受傷
  • Diffuse axonal injury：加速/減速機械性損傷，CT 正常
  • 前顱窩骨折：Raccoon eye、鼻漏、結膜下出血
  • 中顱窩骨折：外耳道出血、CSF滲出、Battle's sign
  • 顏面骨折分類：LeFort I、II、III

EDH vs SDH

  • EDH（硬腦膜上出血）：中腦膜動脈破裂；Lucid interval；紡錘狀（biconvex）；可過中線；不過 skull suture
  • SDH（硬腦膜下出血）：橋靜脈破裂；新月形（crescentic）；不過中線（被falx侷限）；會過 skull suture
  • SDH CT 分期：Hyperdense = acute（hours）；Isodense = subacute（days）；Hypodense = chronic（weeks）
  • Kernohan's phenomenon：EDH/SDH mass effect 推擠對側大腦腳→同側肢體癱瘓

顱內壓（ICP）升高

  • CPP = MAP − ICP
  • Cushing's triad：Hypertension、Bradycardia、Respiratory Irregularity
  • 降 ICP 方法：30–45度躺、20% Mannitol、Hyperventilation（PaCO2 30–35）、抽CSF、High-dose barbiturate、Hypothermia、Decompressive craniectomy、Steroids

蜘蛛膜下腔出血（SAH）

  • 最常見原因：外傷；自發性 SAH：顱內動脈瘤破裂
  • 好發：春秋、55–60歲；動脈瘤位於血管分岔處
  • 典型症狀：突發性劇烈頭痛（thunderclap headache）
  • Kernig sign：屈髖伸膝時大腿後側痛
  • Brudzinski sign：頸前屈→下肢不自主屈曲
  • CSF 特徵：不越抽越淡、WBC↑、離心後黃色、蛋白質↑、opening pressure↑
  • Gold standard 評估：DSA（Digital Subtraction Angiography）
  • 外科處置：Surgical clipping、Coil embolization、Wrapping
  • 併發症：Rebleeding（Grade 1/2 最常見死因）、Hyponatremia、Hydrocephalus、Vasospasm（4–10天，好發第7天）→ Triple H therapy
  • Cerebral salt wasting：IICP→ANP↑→腎Na+和水↑→hypovolemia；治療：補水

顱內出血（ICH）

  • 最常發生位置：基底核 Putamen
  • 最常見病因：高血壓（Charcot-Bouchard's aneurysm）
  • 橋腦血腫 5P：Paralysis、Pulsus parvus、Pinpoint pupil、Pyrexia、Periodic respiration

腦血管畸形

  • AVM：動脈直接注入靜脈（不過微血管）；最常見症狀：出血、癲癇；手術風險：Spetzler-Martin grading
  • Cavernous malformations：最常見症狀 = 癲癇（顳/頂葉）；MRI診斷 → Popcorn appearance
  • Carotid-cavernous fistula：外傷 → Direct type（high flow）；治療：血管氣球栓塞

水腦症

  • 腦室循環：Lateral→Monro→3rd→Aqueduct→4th→Luschka+Magendie→subarachnoid
  • CSF：脈絡叢（Choroid plexus）產生，每天 500mL
  • 水腦症分類：阻塞型（腦室系統阻塞）；交通型（蜘蛛膜顆粒受影響）
  • Dandy-Walker malformation：Luschka和Magendie foramina狹窄→第四腦室擴大
  • 落日眼（Setting sun）：水腦壓迫四疊體→眼皮後翻、無法向上看
  • NPH（Normal Pressure Hydrocephalus）3W：Weird（失智）、Wobbly（步態不穩）、Wet（尿失禁）

腦瘤

  • 最常見原發性腦瘤：星狀細胞瘤（Astrocytoma）
  • 腦轉移順序：肺→乳→腎→腸胃道
  • Glioma WHO 分子標記：IDH wild/mutant、1p/19q codeletion、EGFR、TP53、ATRX
  • Grade IV Glioma 病理特徵：Necrosis（CT見ring enhancement）
  • Oligodendroglioma：IDH mutant + 1p/19q codeletion；組織：Fried egg、chicken wire、calcification
  • Glioma 化療：Temozolomide
  • Medulloblastoma（小孩最常見惡性腦瘤）：5–7歲；MRI = Zuckerguss（icing-like enhance）
  • 天幕下最常見腫瘤：Vestibular schwannoma（聽神經瘤）
  • Meningioma：蜘蛛網膜 cap cell；好發：Parasagittal→Convexity→Sphenoid ridge；Gd-T1 → Dural tail；切除評估：Simpson grading
  • Pituitary tumor：Micro（<1cm）多；最常見功能性：Prolactinoma → 第一線：Dopamine agonist（Bromocriptine/Cabergoline）
  • Parinaud's syndrome：四疊體受傷→眼球向上凝聚力喪失、瞳孔對光反應障礙
  • NF type II：雙側聽神經瘤 + 多發性腦膜瘤
  • Pseudotumor cerebri 治療：Acetazolamide、Diuretics、減重、LP、Shunting

脊椎病變

  • HIVD 最常發生：L4-5、L5-S1；診斷：MRI
  • 腰椎狹窄最常見：L4-5；頸椎狹窄最常見：C6-7
  • Lhermitte's sign → Cervical spinal stenosis
  • C1（Jefferson）骨折：垂直壓迫；anterior + posterior arches 骨折
  • C2 odontoid 骨折最常見：Type II（base断裂，不穩定）
  • Hangman's fracture：Hyperextension + axial loading → C2 pars interarticularis 骨折
  • 脊椎滑脫 Meyerding：Grade 1（1–25%）→ Grade 5（>100%）
  • Brown-Séquard syndrome：脊髓半邊受傷；同側運動+本體感覺喪失；對側溫痛覺喪失；預後佳
  • Central cord syndrome：Hyperextension；披肩式溫痛覺異常（上肢>下肢）
  • 脊柱裂：occulta（最常見）；Meningocele；Myelomeningocele（最嚴重，好發胸腰椎交界）
  • ASIA impairment scale：A完全→E感覺運動正常
  • 脊椎腫瘤分類：Extradural（最多，轉移癌最常見）；Intradural extramedullary（Meningioma/Schwannoma）；Intramedullary（最少，Astrocytoma/Ependymoma）

神經反射（DTR / 肌力）

  • C5/C6：Deltoid、Biceps、Biceps jerk、Supinator jerk
  • C7/C8：Triceps、Triceps jerk
  • L2/L3：Hip flexion
  • L3/L4：Knee extension、Knee jerk
  • L4/L5：Ankle dorsiflexion
  • L5/S1：Big toe extension（dorsiflexion）
  • S1/S2：Achilles jerk
  • S2–S4：Anal cutaneous reflex、Bulbocavernous reflex
  • T6–T8：Autonomous dysreflexia（AD）
  • Beevor's sign：彎頸→肚臍朝頭移動（下腹較上腹無力）→ T10 SCI

三叉神經痛 / 顱縫

  • 三叉神經痛：好發 V2/V3；最常見原因：SCA 血管壓迫三叉神經根；第一線：Carbamazepine
  • Arnold-Chiari I：單純小腦扁桃體下疝；II：+延髓下疝+脊柱裂；III：+腦幹下疝入椎管；IV：+小腦發育不全
  • 舟狀頭（Scaphocephaly）：sagittal suture 過早閉合
  • 腦血流量占 CO 約 15%

🫀 泌尿外科

97 題

腎臟腫瘤

  • 最常見原發性腎臟惡性腫瘤：RCC（Renal Cell Carcinoma）
  • 遺傳性 RCC：VHL disease（小腦血管母細胞瘤+視網膜血管瘤+雙側腎透明細胞癌）
  • RCC Paraneoplastic syndrome：高血壓（40%）、高血鈣（20%）、Stauffer's syndrome（肝功能異常，分泌 GM-CSF）、紅血球增多症（5%）
  • RCC CT 特徵：A phase 較亮 → V phase 較暗（early wash out）
  • AML（angiomyolipoma）：超音波高回音；CT 低密度（脂肪）；<4cm 每年追蹤；合併結節性硬化症 → 雙側
  • 急性腎盂腎炎（APN）：CT 灌流缺失（perfusion defect）；常見菌：大腸桿菌（80%）
  • 小兒腎臟最常見惡性腫瘤：Wilms' tumor（Nephroblastoma）
  • 腎盂/輸尿管癌影像：Filling defect

膀胱疾病

  • 最常見膀胱癌：Transitional cell carcinoma（UCC）；第二常見泌尿道惡性腫瘤
  • Squamous cell bladder carcinoma：慢性發炎（膀胱炎/結石/長期導尿/埃及血吸蟲）
  • 膀胱癌轉移：骨頭、肺、肝
  • BCG 膀胱灌注適應症：Tis、Ta（large/multiple/high grade/recurrent）
  • 最常轉移至膀胱：黑色素瘤
  • 血尿最常見原因：UTI
  • 膀胱外傷診斷：逆行性膀胱攝影
  • Intraperitoneal rupture：膀胱滿時；Flame sign；須手術
  • Extraperitoneal rupture：合併骨盆骨折；淚滴狀；自行癒合
  • VUR 分級：I（輸尿管）→ III（輕微擴大）→ V（明顯擴大，乳頭壓跡消失）

攝護腺

  • 最常見泌尿系統癌症：攝護腺癌（Adenocarcinoma，70% 在 Peripheral zone）
  • BPH：Transitional zone；IPSS = FUN-WISE；手術絕對適應症：反覆尿滯留/血尿/UTI/腎功能不佳/水腎/膀胱結石
  • PSA 正常值：<4 ng/mL；年齡分層：40–49=0–2.5；50–59=0–3.5；60–69=0–4.5；70–79=0–6.5
  • PSA 相關：與攝護腺癌發生率有關；與嚴重度/預後無關
  • 攝護腺癌骨轉移：腰椎（中軸骨），Osteoblastic 病灶
  • TUR syndrome：低滲透壓液進入血流→低血鈉；症狀：噁心、嘔吐、意識改變、高BP、心跳慢
  • 維生素 D 可降低攝護腺癌風險

睪丸 / 陰莖疾病

  • 睪丸扭轉（Testicular torsion）：15歲青少年；Bell Clapper's deformity；突然劇痛；提睪時加劇（Prehn's sign）；提睪肌反射消失（Rabinowitz's sign）；Doppler 低血流
  • 精索靜脈曲張：好發左側（直角注入左腎靜脈 + Nutcracker effect）；Scrotal Doppler（>3mm）；最常見男性不孕原因
  • 副睪炎：逐漸疼痛；Doppler high flow；抬高陰囊可緩解
  • Fournier gangrene：會陰部壞死性筋膜炎
  • 隱睪症：手術時機 <1歲
  • 睪丸癌：大部分生殖細胞癌；年輕男性（15–30歲）最常見固態腫瘤；Choriocarcinoma 以血液轉移
  • 陰莖癌：HPV type 16；SCC；Buck's fascia 阻擋血液轉移；淋巴路徑：腹股溝→骨盆LN
  • 兒童最常見睪丸腫瘤：Teratoma、Yolk sac tumor
  • LH → Leydig cell（睪固酮）；FSH → Sertoli cell（精子形成）

尿路結石

  • 輸尿管三處狹窄：UPJ、輸尿管-髂動靜脈交叉、UVJ
  • 最常引起感染結石：磷酸胺鎂（Struvite）→ 鹿角狀、尿pH >7.2、Proteus
  • 尿酸結石：男性/痛風；pH <5.5；X光 Radiolucent
  • Radiolucent 結石：尿酸、黃嘌呤、Indinavir（CT 也看不到）
  • 抑制結石離子：硫（Sulfate）、鎂（Mg）、檸檬酸（Citrate）
  • ESWL 禁忌症：懷孕、腹主動脈瘤、出血傾向、完全阻塞伴重度水腎、心律器、骨骼畸形
  • >2cm 結石：PCNL（經皮腎造口碎石術）
  • Type I RTA → 腎結石

排尿功能 / 腎上腺

  • Pves = Pabd + Pdet
  • S2–4以上病灶：膀胱過動、逼尿肌反射過強、DSD
  • S2–4以下病灶：膀胱鬆弛、容量增大、逼尿肌無反射、overflow incontinence
  • 腎上腺皮質層：Glomerulosa→礦物皮質素；Fasciculata→糖皮質素；Reticularis→雄性素；髓質→兒茶酚胺
  • Pheochromocytoma 10% rule：10% family/bilateral/malignant/child/extra-adrenal/calcification/unrelated to HTN
  • Pheochromocytoma 核醫檢查：MIBG（I-131-meta-iodobenzylguanidine）
  • 腎臟移植：首選切除活體捐贈者左腎（腎靜脈較長）；種植右髂窩（血管較水平）

⚕️ 外科

104 題

營養

  • 評估營養狀況：Albumin、Pre-albumin、Transferrin
  • 腸胃道營養優點：維持黏膜完整性、降低細菌 translocation、提高免疫、便宜、少併發症；最常見併發症：腹瀉
  • TPN 適應症：腸道失功能、禁食 >7–14 天；需中央靜脈給予（較高滲透壓）
  • TPN 容易缺乏微量元素：Zn、Cu、Se、Cr、Mn
  • Refeeding Syndrome：三低一高（低血鉀、低血磷、低血鎂、高血糖）
  • 熱量估算：輕中度外傷 25–35 Kcal/kg；重度 40–45；肝衰竭 25–30
  • 每日水分 100-50-20 rule：前10kg×100 + 第二10kg×50 + 剩下×20 (mL/day)
  • 燒燙傷輸液：Parkland = 4mL/kg/%TBSA（前8hr給一半）
  • 燒燙傷營養：Curreri = 25×體重 + 40×%TBSA（>50%以50%計）

電解質

  • 正常血鈉：135–145 mEq/L；Hypervolemic Hyponatremia→利尿劑；Euvolemic Hyponatremia→限水+3% N/S（矯正速度 ≤10–12 mEq/L/day，過快→Central Pontine Demyelination）
  • TURP syndrome：BPH手術大量沖洗液→低血鈉
  • 神經外科低血鈉：常見原因 SIADH
  • 正常血鉀：3.5–5.0 mEq/L；低血鉀→最易導致腸阻塞
  • 高血鉀治療（FAT DICKS）：Furosemide、Albuterol/Terbutaline、Dialysis、Insulin/glucose、Calcium gluconate、Kayexalate/Kalimate/Lokelma、Sodium bicarbonate
  • 正常血鈣：8–10 mEq/L；低血鈣 → Chvostek sign、Trousseau sign
  • 高血鈣原因：惡性腫瘤（最常見）、副甲亢、肉芽腫、Thiazide、Vit D過多
  • High AG代謝性酸中毒（MUDPILERS）：Methanol、Uremia、DKA、Propylene glycol、Isoniazid、Lactic acidosis、Ethylene glycol、Rhabdomyolysis、Salicylates

休克 / 輸液

  • CVP 上升的休克：心因性、阻塞性；HR 下降的休克：神經性
  • Hypovolemic shock 分級 II：BP正常、HR>100、RR 20–30、U/O 20–30cc/hr；失血750–1500mL（15–30%）
  • Hypovolemic shock 分級 III：BP降低、HR>120、RR 30–40、U/O 5–15cc/hr；失血1500–2000mL（30–40%）
  • 正常排尿量：成人 >0.5cc/kg/hr；小孩 >1mL/kg/hr；新生兒 >2mL/kg/hr
  • 升壓劑順序：1st Norepinephrine→2nd Vasopressin→3rd Epinephrine
  • 大量輸血定義：一次>2500mL 或24hr內>5000mL；pRBC:FFP:Platelet = 1:1:1
  • Lethal Triad：Hypothermia、Coagulopathy、Metabolic Acidosis
  • 小兒輸液：20mL/kg crystalloid(N/S)→重複後無改善→10mL/kg pRBC
  • SIRS 診斷（≥2項）：BT>38或<36；HR>90；RR>20或PaCO2<32；WBC>12000或<4000
  • EGDT 6hr目標：CVP 8–12；MAP>65；ScvO2>70%

外科傷口 / 感染

  • 院內感染順序：1st UTI、2nd 外科傷口感染、3rd 肺炎（但肺炎是最常見死因）
  • 傷口分類與抗生素：
    Clean（無預防性抗生素；若長時間/植入物可用第一代Cepha）
    Clean-contaminated（第一代Cepha + Aminoglycoside + Unasyn/Cefmetazole）
    Contaminated/Dirty（治療性抗生素，第二代Cepha + Aminoglycoside）
  • 手術部位感染（SSI）：術後30天內（植入物1年）；最常見：淺層切口感染
  • Pseudomembranous colitis 治療：口服 Vancomycin 或 Metronidazole
  • 動物咬傷：貓咬→Pasteurella multocida；狗咬→Pasteurella spp.；猴子咬→B virus；海水魚咬→Vibrio spp.

移植免疫

  • MHC：第6對染色體短臂；Class I（HLA-A/B/C）存在有核細胞+血小板；Class II（HLA-DP/DQ/DR）存在APC（B cell/Macrophage/DC）

  • PTLD：與 EBV 有關

外傷 / 腔室症候群

  • 腹部鈍傷：1st 脾臟；2nd 肝臟
  • 刀傷最常傷：肝臟；槍傷最常傷：小腸
  • FAST 部位：Pericardium、Morison's pouch、perisplenic space、rectovesicular space
  • 腹腔室症候群：腹內壓>25cmH2O；治療：外科減壓
  • 肌肉腔室症候群：室間壓>30cmH2O；6P症狀（Pain最早最不專一）；最常發生：小腿；治療：fasciotomy
  • DVT/PE 危險因子：Virchow's Triad（Stasis、Hypercoagulable state、Endothelium injury）
  • 吸入性灼傷診斷：支氣管鏡
  • 胸管位置：腋中線/腋前線第4或第5肋間

腫瘤標記 / 倫理法規

  • 腫瘤標記：CA199→胰臟癌；AFP→肝癌；CEA→大腸癌；HCG→Choriocarcinoma；Bence Jones protein→Multiple Myeloma
  • Calot's triangle：Common hepatic duct + Cystic duct + Liver edge
  • DNR：適用心跳或呼吸停止時，不限制其他治療
  • 末期親屬代理同意順序：配偶→成年子女/孫→父母→兄弟姐妹→祖父母→曾祖父母/三親等旁系→一親等直系姻親
  • 65歲以上最常見外傷原因：跌倒
  • MELD score：Total Bilirubin、Creatinine、INR、Na+、Albumin、Age
  • 電阻最低：神經、血管、肌肉；最高：皮膚

困難插管評估

  • 3-3-2 rules：張口3指幅；下巴前緣到舌骨3指幅；舌骨到甲狀軟骨2指幅
  • Mallampati III/IV：困難插管（III=uvula base；IV=hard palate）
  • BURP maneuver：壓甲狀軟骨（Thyroid cartilage）→ vocal cord 更易顯現
  • Sellick maneuver：壓環狀軟骨（Cricoid cartilage）→ 防止 aspiration
  • 困難插管+困難通氣：Flexible fiberoptic intubation（Awake intubation）
  • CICO（Cannot Intubate Cannot Oxygenate）→ Cricothyroidotomy（環甲膜切開術）
  • Cuff pressure：20–30 cmH2O
  • RSI 7P 最優先步驟：Preoxygenation

術中監測

  • 低體溫定義：中心體溫 <36°C；術中監測體溫目的：及早發現惡性高熱、防止低體溫
  • 假性高 SpO2：CO中毒、methemoglobinemia
  • 假性低 SpO2：低血壓、貧血、深色指甲油、抖動
  • Capnography 分期：Phase I = dead space；II = mixed；III = alveolar gas；0 = inspiration
  • A-line 最常使用血管：橈動脈（Radial artery）
  • Swan-Ganz catheter 路徑：IJV→RA→RV→PA→pulmonary capillary
  • Cardiac Index（CI）：CO / BSA
  • 全身麻醉 BIS 目標：40–60
  • 睫毛反射消失 → Stage II（Excitement/Delirium）
  • 術中血糖目標：≤180 mg/dL

吸入性麻醉劑（MAC）

  • MAC 定義：一大氣壓下，50%病人接受刺激後不動的劑量
  • MAC 最小：Halothane；MAC 最大：N2O
  • Desflurane：最刺激呼吸道（易氣管痙攣）；遇 CO2 吸附劑→產生 CO
  • Sevoflurane：遇 CO2 吸附劑→產生 Compound A（腎毒性）

肌肉鬆弛劑（NMBDs）

  • 非去極化肌鬆劑分類：Steroidal（-ronium）；Benzylisoquinolinium（-curium）
  • Hofmann elimination：不須肝腎，直接體內自然降解；代表藥：Atracurium、Cisatracurium
  • TOF 監測肌肉/神經：adductor pollicis brevis / 尺神經
  • TOF fade 現象：Non-depolarizing NMBDs
  • 拔管條件（ASA）：TOF ratio ≥0.9
  • 給解藥條件（ASA）：TOF count=4 且 TOF ratio ≥0.4
  • Sugammadex（Bridion）：逆轉 Steroidal NMBDs（Vecuronium/Rocuronium）；腎臟排出
  • Edrophonium：Tensilon test（診斷重症肌無力）
  • Pyridostigmine：治療重症肌無力
  • Glycopyrrolate：唯一四級胺 anticholinergic，不過 BBB

局部麻醉劑

  • Amide 類（藥名有兩個 i）：肝臟代謝、過敏率低
  • Ester 類（藥名一個 i）：Plasma cholinesterase 水解、代謝產物 PABA 過敏率高
  • 機轉：使鈉離子通道不活化，提高動作電位閾值
  • Differential blockade 順序：B（交感）→ C（感覺）→ A（運動）
  • 加 Epinephrine：血管收縮→局麻作用延長、減少全身吸收
  • LAST（Local Anesthetic Systemic Toxicity）：解藥 = 20% lipid emulsion
  • Lidocaine 最大劑量：4.5mg/kg；加 epi → 7mg/kg
  • PDPH 治療：Epidural Blood Patch
  • Loss of resistance（Epidural）：針尖通過黃韌帶（Ligamentum flavum）

疼痛術語

  • Allodynia：non-noxious 刺激→痛覺（異感痛）
  • Analgesia：痛刺激卻無痛感
  • Hyperalgesia：輕微痛刺激→強烈痛覺
  • Dysesthesia：令人不愉快的異常感（非痛）
  • Paresthesia：所有感覺異常的總稱
  • Opioid 副作用受器：mu-receptor
  • Meperidine（Demerol）→ 慢性腎衰竭累積 Normeperidine → 癲癇
  • Naloxone：呼吸抑制/搔癢解毒；Methylnaltrexone：便秘解毒
  • 慢性疼痛定義：>3個月
  • PHN（Postherpetic Neuralgia）：Herpes Zoster 癒合後疼痛>3個月
  • Gabapentin/Pregabalin：抑制鈣離子通道→神經痛
  • 癌痛 3B 原則：By the mouth、By the clock、By the ladder
  • 三叉神經痛首選藥：Carbamazepine

惡性高熱（Malignant Hyperthermia）

  • 機轉：RYR1 基因突變→鈣離子通道無法關閉→Ca2+ 累積→肌肉持續收縮
  • 早期症狀：End-tidal CO2↑、心跳加快
  • 治療：Dantrolene（抑制 Ryanodine receptor）
  • 禁用：CCB（高血壓時）

術後 / ARDS / Sepsis

  • 最常見麻醉併發症（術後恢復室）：PONV
  • Apfel score PONV 危險因子：女性、不抽菸、動暈症/PONV病史、術後 opioid
  • ARDS 定義：急性7天內雙側肺浸潤無其他原因
    • 嚴重度P/F ratio（mmHg）
    Mild200–300
    Moderate100–200
    Severe<100
  • ARDS 治療：Low TV（6mL/kg）、Plateau pressure ≤30、PEEP ≥5、Prone position、VV-ECMO
  • SOFA：腦/心/肝/肺/腎/血；qSOFA：RR≥22、Altered mentation、SBP≤100
  • Surviving Sepsis Campaign：3hr內30mL/kg balanced crystalloid；MAP>65；1st 升壓劑 Norepinephrine；血糖144–180 mg/dL
  • 術後高體溫時間規律：2天內→肺塌陷；3天→肺炎/UTI；5天→傷口感染/腹內膿瘍；7天→DVT

乳癌流行病學 / 危險因子

  • 台灣女性發生率第一名：乳癌
  • 乳癌危險因子：>40歲、乳癌家族史、BRCA1/2 mutation、初經早、停經晚、第一胎晚生、未生育、賀爾蒙治療>5年、high breast density、放射線、breast tumor
  • 乳癌最常轉移：骨頭（70%）、肺臟、淋巴結、腦部、肝臟

乳癌病理分型

  • DCIS 預後（最好→最差）：papillary → cribriform → solid → comedo
  • LCIS：E-cadherin 缺乏
  • 侵襲性乳癌最常見：Infiltrating ductal cancer
  • 侵襲性乳癌預後最好：Mucinous cancer
  • BRCA1 mutation → Basal-like breast cancer（TNBC）
  • IHC 乳癌分型標記：ER、PR、HER2/neu（ERB2）、Ki-67
  • 乳癌預後（最好→最差）：Luminal A（ER/PR+, HER2-, Ki67<14%）→ Luminal B（ER/PR+, HER2+/-, Ki67>14%）→ HER2（ER/PR-, HER2+）→ TNBC（ER/PR-, HER2-）
  • 腫瘤大小（T stage）：T1 ≤2cm；T2 2–5cm；T3 >5cm；T4 侵犯皮膚/胸壁
  • 術後追蹤 marker：CA15-3、CEA

手術治療

  • 前哨淋巴結（Sentinel LN）定義：最先受侵犯、最可能轉移的第一顆/群淋巴結
  • SLNB 目的：減少腋下廓清的併發症（淋巴水腫、麻痺、活動受限）
  • SLNB 定位方法：甲基藍 + 同位素注射於腫瘤旁
  • 乳房保留手術 + 術後放療 vs 改良式根除性全切除術 → 臨床預後相同

全身性治療

  • 賀爾蒙治療：Tamoxifen（SERM，停經前第一線）、Aromatase inhibitor、LH-RH agonist
  • HER2 標靶治療：Trastuzumab（Herceptin）、Pertuzumab（Perjeta）、Lapatinib（Tykerb）
  • 化療副作用：紫杉醇 → 周邊神經病變、水腫；Anthracycline → 心臟毒性

乳房重建

  • 立即重建 vs 延遲重建：存活率與復發率無差異
  • 延遲重建時間點：化放療後3個月，或術後2年無復發
  • 最常使用自體皮瓣：TRAM flap（腹直肌皮瓣）；相對禁忌：肥胖、曾腹部手術
  • 闊背肌皮瓣（LD flap）：背部脂肪少，適合乳房體積小者；體積大時合併義乳植入

傷口重建 / 重建階梯

  • Reconstructive ladder（重建階梯）思考順序：自行癒合 → 直接縫合 → 皮膚移植（skin graft）→ 皮瓣手術（local → distant → free flap）
  • 傷口癒合四期：止血期 → 發炎期 → 增生期（肉芽 → 傷口縮合 → 上皮化）→ 重塑成熟期
  • 傷口癒合細胞出現順序：Platelets → Neutrophils → Monocytes → Macrophages → Fibroblasts → Lymphocytes
  • 主要負責 wound contraction：肌纖維母細胞（myofibroblasts）
  • 肉芽組織期 collagen：Type III collagen；重塑成熟期逐漸替代為 Type I collagen
  • 影響傷口癒合 — 局部：氧合、灌流、感染、異物、血腫、放療
  • 影響傷口癒合 — 全身：年紀、營養不良（Vit A/C、Zn/Fe/Cu）、抽菸、類固醇、抗癌藥、糖尿病、尿毒症
  • 拆線時機：臉/頭皮 1週；頸部 8–10天；其他部位 2週

壓瘡（Pressure Sore）

  • 正常 capillary filling pressure：16–32 mmHg；接受 60 mmHg 超過 1 小時 → 易形成壓瘡
  • 壓瘡分期：Stage I 皮膚完整；Stage II 部分真皮缺損（open ulcer）；Stage III 全層缺損（可見皮下脂肪）；Stage IV 全層缺損（暴露骨、肌腱、肌肉）
  • 治療：Stage I/II → 保守（減壓、敷料）；Stage III → 植皮；Stage IV → 局部肌皮瓣（臀大肌皮瓣）

Skin Graft

  • STSG vs FTSG：STSG（上皮+部分真皮）容易 take、易色素沉積、secondary contraction 多；FTSG（上皮+全層真皮）較難 take、美觀、primary contraction 多、感覺恢復快
  • Graft healing 步驟：Adherence → Take（Plasmatic circulation → Inosculation → Revascularization）
  • 最容易 graft failure 的階段：Inosculation
  • 常見失敗原因：infection、hematoma、seroma、movement

皮瓣手術（Flap Surgery）

  • Random flap 血液供應：dermal and subdermal plexus
  • Axial/Pedicle flap 型態分類：半島型（Peninsular，血管組織皆相連）、島嶼型（Island，只有血管相連）、游離型（Free，血管組織皆分離）
  • Mathes & Nahai classification（muscle flap 血管分型）：
    Type I 單一血管（TFL, soleus）；Type II 一主血管+小血管（Gracilis, Gastrocnemius）；
    Type III 兩條主血管（Gluteus maximus, Pectoralis major, Rectus abdominis）；
    Type IV 數條相同血管（Sartorius）；Type V 一主+小血管分段（Latissimus dorsi）
  • Z-plasty 角度 → 增加疤痕長度：30°→25%；45°→50%；60°→75%；75°→100%；90°→120%
  • 皮瓣存活評估：Color、Capillary blanching、Warmth、Stab wound bleeding
  • 動脈受阻 vs 靜脈受阻：溫度 快降(a.) / 慢降(v.)；組織 變虛(a.) / 變硬(v.)；顏色 蒼白(a.) / 瘀青(v.)

顯微手術 / 斷指重接

  • Warm / Cold ischemia time：骨/肌腱/皮膚/一般斷指：Warm 8–12 hr，Cold 24 hr；肌肉：Warm 2–6 hr，Cold 8–12 hr；大斷肢：Warm 4–6 hr，Cold 10–12 hr
  • 顯微血管吻合：End-to-end（血管大小相近，直接血流，小血管最常用）；End-to-side（血管大小不同）；兩者血流暢通機率無差
  • 高壓氧治療先決條件：確認血液循環暢通
  • 斷指重接禁忌症：Multi-level amputation、severe crushing、life-threatening injuries、prolonged warm ischemia time、mentally unstable、proximal to FDS
  • Sunderland 神經損傷分級：Grade I Neurapraxia；Grade II Axonotmesis；Grade III–V Neurotmesis（依 endoneurium/perineurium/epineurium 受損程度）；Grade VI neuroma-in-continuity

乳房重建 / 隆乳

  • 最常使用的乳房重建方式：義乳乳房重建（Implant-based reconstruction）
  • 自體皮瓣乳房重建比較：Pedicled TRAM（血供差、壞死高、腹部疝氣高）→ Free muscle-sparing TRAM（腹部風險低）→ Free DIEP（幾乎無腹部後遺症）；Latissimus dorsi（常需合併義乳）
  • 隆乳最常見後遺症：夾膜攣縮（Capsular contracture）

先天異常 / 唇顎裂

  • 最常見先天顏面異常：唇顎裂
  • 唇裂手術 Rule of 10：年齡 > 10 週（出生後 3 個月）、體重 > 10 lbs、Hgb > 10、WBC < 10000
  • 唇顎裂治療流程：3 個月大 唇裂修補 → 9–18 個月 顎裂修補+中耳引流 → 5 歲 咽瓣手術+語言治療 → 6–11 歲 鼻頭矯正/牙床裂/植骨 → 成年 正顎手術
  • 最常見手指先天畸形：併指（Syndactyly）；最常發生於三四指間 → 二三指間
  • 多指（Polydactyly）最常發生：小指側（postaxial）→ 大拇指側（preaxial）

主動脈剝離（Aortic Dissection）

  • 分類（時間）：急性（≤14天）/ 慢性（>14天）
  • Stanford 分型：Type A（侵犯 ascending aorta）→ 緊急手術；Type B（未侵犯 ascending aorta）→ 藥物/視情況介入
  • DeBakey 分型：Type I（升主動脈+降主動脈）/ Type II（升主動脈）/ Type III（降主動脈）
  • 臨床特徵：突發性劇烈胸痛、interscapular pain、tearing pain、malperfusion syndrome、cardiac tamponade
  • CXR：主動脈邊界模糊、氣管右偏、縱膈腔變寬（widened mediastinum）
  • Contrast CT：intimal flap 分隔 True lumen（較亮）與 False lumen（較暗）
  • 處置：急性 Type A → 緊急手術；complicated 急性 Type B → 手術或 endoluminal intervention；uncomplicated 急性 Type B → 藥物（anti-impulse therapy: Beta-blocker、CCB、sodium nitroprusside）；慢性 → 藥物追蹤（最大直徑 >5cm 或每年增加 >0.5cm 則開刀）

動脈瘤（Aneurysm）

  • 最常見原因：Degenerative aneurysm
  • Infected（Mycotic）aneurysm 致病菌：S. aureus → Salmonella spp.、P. aeruginosa
  • 好發位置：腹主動脈（腎動脈以下）
  • DTAA 分型：Type A（左鎖骨下 a. → 第6肋間）/ Type B（第6肋間 → 橫膈）/ Type C（全降主動脈）
  • TAAA 分型：I（左鎖骨下 → 腎動脈）/ II（左鎖骨下 → iliac bifurcation）/ III（6th ICS → iliac bifurcation）/ IV（橫膈 → iliac bifurcation）/ V（6th ICS → 腎動脈）
  • AAA 分型：Infra-renal（I）/ Juxta-renal（II）/ Para-renal（III）/ Supra-renal（IV）
  • 手術適應症：最大直徑 >5.5cm（胸 >6cm、腹 >5cm、髂動脈 >3.5cm）、每年增加 >1cm 或半年 >0.5cm、症狀持續加重、女性 >4.5cm（BSA 較小）、saccular/mycotic/pseudoaneurysm/dissecting/fistula
  • EVAR Endoleak 分型：Type I（近端 Ia/遠端 Ib 密封不全）/ Type II（分支動脈回流，最常見）/ Type III（支架結構問題：modular disconnection、graft fracture）/ Type IV（支架織物滲漏）

AMI 機械性併發症 / CABG

  • IABP 作用：降低 afterload（SVR）、增加 coronary perfusion；術前置放以穩定血液循環

心臟移植（Heart Transplantation）

  • 絕對適應症：refractory cardiogenic shock、持續使用 IV inotropics 維持器官灌流、Peak VO₂ <10 mL/kg/min、嚴重心肌缺血無法以 CABG/PCI 改善、refractory ventricular arrhythmia
  • 相對適應症：Peak VO₂ 11-14 mL/kg/min + 日常活動受限、refractory unstable angina（無法以其他方法控制）
  • 不足以移植：單純 LVEF 低下、NYHA class III/IV、Peak VO₂ >15 mL/kg/min
  • 絕對禁忌症：嚴重肺高壓（PVR >6 WU）、CCr <50 mL/min、肝功能異常、severe COPD、malignancy、active infection、DM with secondary organ damage
  • 相對禁忌症：年齡 >65 歲、肥胖、active peptic ulcer、drug abuse

IABP / 心肺體外循環（CPB）

  • IABP 置放位置：降主動脈靠近主動脈弓處
  • IABP 絕對禁忌症：severe AR、Aortic dissection、Aneurysm、severe aorto-iliac calcification、chronic end-stage heart failure
  • CPB 導管位置：升主動脈（回輸動脈血）、上腔靜脈（引流頭部與上肢靜脈血）、下腔靜脈（引流腹部與下肢靜脈血）
  • CPB 注意事項：灌注 cardioplegia（高 K⁺ 溶液）→ 心肌停止跳動降低需氧量；低體溫療法（20°C）→ 降低全身代謝；引流心臟內血液 → 心肌鬆弛；維持腦部灌流（innominate a. → carotid a.，避免中風）
  • Heparin 解毒劑：Protamine

解剖概論

  • 後腹膜器官：升結腸、降結腸、直腸
  • White line of Toldt：壁層腹膜沿升降結腸外側與腸繫膜轉折處，手術上藉此分離結腸與後腹壁

  • 最常見：乙狀結腸扭轉（80–90%）；第二：盲腸扭轉（<5%）

  • 真 vs 假憩室：真憩室→整層腸壁膨出；假憩室→僅黏膜穿過肌肉層膨出（大腸憩室屬假憩室）

  • 下消化道出血最常見原因：大腸憩室
  • 憩室炎症狀：左下腹疼痛，可轉移至恥骨上、左鼠蹊部、背部

細菌感染

寄生蟲感染

  • Scabies 一線治療：Permethrin 5%（首選）；其他：Lindane、Benzyl benzoate、Crotamiton、Ivermectin（口服）

黴菌感染

  • 最常見的黴菌足部感染：Tinea pedis（足癬）
  • 最常見的黴菌甲感染：Tinea unguium（甲癬 / onychomycosis）

  • Chromomycosis（著色黴菌病）：KOH → copper pennies（銅幣狀 sclerotic bodies）
  • Candidiasis：最常見於免疫不全者（immunocompromised）
  • Griseofulvin：僅適用於皮癬菌（Dermatophytes），不適用 Candida / Malassezia
  • Onychomycosis 治療：Terbinafine 或 Itraconazole（非 Griseofulvin）

自體免疫水泡疾病

  • Pemphigus vulgaris（尋常性天疱瘡）：Nikolsky sign (+)；suprabasal 裂隙；黏膜受侵；DIF：網狀 intercellular IgG（IC pattern）
  • Pemphigus foliaceus（落葉性天疱瘡）：Nikolsky sign (+)；subcorneal 裂隙；無黏膜受侵；DIF：同 PV（IC pattern）
  • Bullous pemphigoid（大疱性類天疱瘡）：老年人；tense bullae；Nikolsky sign (-)；subepidermal 裂隙；DIF：linear IgG + C3（basement membrane zone）

  • Isotretinoin（A酸）絕對禁忌症：懷孕（pregnancy）→ 致畸胎性極強

  • ICD（Irritant Contact Dermatitis）：較常見；侷限暴露位置；界線分明；達到閾值即引發（非免疫）

扁平苔癬 / 藥物疹

  • Lichen Planus 5P：Planus（flat-topped）、Pruritic、Polygonal、Purple、Papule；Wickham striae；Koebner phenomenon
  • Fixed Drug Eruption：每次服相同藥後在相同部位出現皮疹；好發生殖器、肛門周圍

SJS / TEN

  • 常見致病藥物：Carbamazepine（HLA-B*1502）、Allopurinol（HLA-B*5801）、Abacavir（HLA-B*5701）、Phenytoin、Sulfa 類、NSAIDs

  • 特徵：好發 23 歲或 55 歲；HLA-Cw6；Th1/Th17；Beta-blocker 可誘發或惡化；好發頭皮、肘膝、腹股溝

良性皮膚腫瘤

  • Hemangioma（血管瘤）：新生兒最常見的腫瘤
  • Seborrheic keratosis（脂漏性角化症）：最常見良性上皮腫瘤；老人斑；不會癌化；表面油光蠟滴狀；Leser-Trelat sign（突發多發性 SK）→ paraneoplastic syndrome
  • Actinic keratosis（光化性角化症）：SqCC 前期病變；光曝部位；atypical keratinocytes（未影響整層表皮）
  • Keratoacanthoma（角化棘皮瘤）：單一圓頂突起結節；充滿角質鱗屑的中央火山口凹陷（Crater）

黑色素瘤 Melanoma

  • ABCDE rule：Asymmetry、Border irregular、Color variation、Diameter >6mm、Enlargement/Elevation
  • 四種亞型
    • Superficial spreading melanoma（SSM）：最常見；女性下肢/男性上背
    • Nodular melanoma：第二常見；生長快速；外觀如藍莓
    • Acral lentiginous melanoma（ALM）：東方人（台灣）最常見；好發手掌/足底/指甲下；Hutchinson nail sign
    • Lentigo maligna melanoma：老年人面部
  • 預後因子：Tumor thickness（最重要）、Histologic ulceration、LN involvement、microscopic satellitosis、vascular invasion、mitotic rate

皮膚惡性腫瘤

  • BCC（Basal cell carcinoma）：最常見皮膚癌；>40歲男性；UV 相關；少轉移、預後良好；表面 Pearly（珍珠光澤）+ Telangiectasia
    • 亞型：Nodular（最常見）、Ulcerating（Rodent ulcer）、Pigmented、Sclerosing、Superficial
    • 病理：high N/C ratio、retraction artifact、tumor island、palisading cells
  • SqCC（Squamous cell carcinoma）：第二常見皮膚癌；Bowen's disease = SqCC in situ（整層表皮 atypical keratinocytes）
  • KS（Kaposi's sarcoma）：HHV-8；好發 AIDS；侵犯內臟（胃腸/肝脾/肺）、淋巴（淋巴水腫）
    • 亞型：典型（老人男性下肢）、地域型（赤道非洲，好發放療）、免疫抑制型（器官移植，停藥可改善）
    • 病理：spindle cell 旋渦狀；irregular slit-like vascular channels；間隙內紅血球
  • Mycosis fungoides（蕈狀肉芽腫）：最常見皮膚 T 細胞淋巴瘤

遺傳性皮膚病 / 神經皮膚症候群

  • NF1（第一型神經纖維瘤）：自體顯性（chr 17）；Café-au-lait spots（最先出現）；腋下/鼠蹊部雀斑；神經纖維瘤；雙側視神經膠瘤；iris Lisch nodules
  • NF2（第二型神經纖維瘤）：自體顯性（chr 22）；預後差；雙側聽神經瘤；青春型白內障
  • TSC（結節性硬化症）：自體顯性（chr 9: TSC1/hamartin；chr 16: TSC2/tuberin）；ash-leaf spots、confetti skin lesions、shagreen patch；infantile spasm
  • Ichthyosis vulgaris（尋常性魚鱗癬）：自體顯性（profilaggrin 基因突變）；四肢伸側魚鱗狀（屈側皺褶不受侵犯）；冬乾加重；易併發 AD、乾癬
  • Darier's disease：自體顯性（chr 12: ATP2A2 → SERCA2 calcium pump）；好發皮脂區/腋下/鼠蹊；指甲紅白並列縱條紋
  • Zinc deficiency（鋅缺乏）：Acrodermatitis enteropathica；腹瀉、肢端/生殖器/肛門濕疹樣病變、ALP↓

其他皮膚疾病

  • Keloid（蟹足腫）治療：局部注射類固醇、冷凍治療、放射線治療、染料雷射、矽膠凝膠/片壓迫、特殊情況手術切除（如穿耳洞）
  • Acanthosis nigricans（黑色棘皮症）：天鵝絨狀皮膚增厚；色素沉澱好發腋下/頸部/鼠蹊皺褶；與肥胖、胰島素阻抗、高雄性素有關；Paraneoplastic syndrome（最常合併胃癌）
